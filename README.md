# Inscrire mon logement — Appart Capsule

Page web publique du parcours d'inscription d'un logement (version compilée).

- Source : dépôt privé `capsule-onboarding` (dossier `site_web/`). Ne pas modifier les fichiers ici à la main : recompiler puis remplacer.
- Envoi final : webhook Make d'inscription déjà en production (même format que l'app).
- Paramètre `?utm_source=…` pour savoir d'où vient le propriétaire (ex. `?utm_source=webflow`).
